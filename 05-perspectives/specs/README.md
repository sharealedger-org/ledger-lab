# Experiment Specifications

This directory will contain versioned, machine-readable experiment manifests.

Each specification should declare:

- experiment ID and version;
- workload and fixture/data source;
- materialization level;
- active perspectives;
- active step-up rules;
- shared-core policy;
- expected control totals;
- metric weights and units;
- replication requirements;
- output locations.

Specifications describe runs. They must not contain generated results.
