# Perspective Fixtures

Small synthetic fixtures will live here until a suitable public source supports the required perspective economics.

Fixtures should include enough data to demonstrate:

- one shared customer/instrument core;
- at least one reusable step-up;
- at least two perspective-specific step-ups;
- balanced generated entries;
- a changed rule or effective date;
- reconciliation to the shared core.

Synthetic data must remain clearly separate from the Virginia public-data experiment.
