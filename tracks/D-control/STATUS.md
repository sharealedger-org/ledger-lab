**Bob's refinements to item 5, for the owner to accept or reject:**

- **The cost of a capability is its incremental cost (owner, 2026-11-13).** "Files read" is the wrong measure: a CKB pass can carry more capabilities without added overhead, so a new view or engine riding an existing ordered stream reads nothing more. A capability that needs a **new sort order** adds a pass and a sort (`02-foundation/README.md`); one that does not, should not. On the control, the equivalent is added index builds, queries, rebuilds and database bytes. A **common I/O counter** for both systems is still to be chosen, because the CKB's logged input bytes and the control's SQLite page reads are not the same thing.
